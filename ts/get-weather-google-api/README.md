# Get Weather with Google API

This TypeScript example gets current weather for an address using Google APIs. It first resolves the address with the Google Geocoding API, then calls the Google Weather API with the resolved coordinates.

Enable the Google Geocoding API and Weather API for the API key before running this example.

## Environment Variables

```sh
GOOGLE_CLOUD_API_KEY=<your-google-cloud-api-key>
ALL_PROXY=<optional-socks-proxy-url>
all_proxy=<optional-socks-proxy-url>
```
