# AutoSend Email

This TypeScript example sends text, HTML, or template-based email with AutoSend. It supports sender information, recipient information, reply-to settings, unsubscribe groups, and template dynamic data.

## Environment Variables

```sh
AUTOSEND_API_KEY=<your-autosend-api-key>
AUTOSEND_FROM_EMAIL=<sender-email>
AUTOSEND_FROM_NAME=<sender-name>
AUTOSEND_REPLY_TO_EMAIL=<optional-reply-to-email>
AUTOSEND_REPLY_TO_NAME=<optional-reply-to-name>
```
